# Homedine - Eco-Friendly Kitchenware Landing Page

A modern and fully responsive React landing page for _Homedine_, a fictional eco-friendly kitchenware brand.

This project was built as a _Frontend Internship Task_ with a focus on clean UI, reusable components, and a fully working Add-to-Cart system.

## Features

- Fully responsive design (Mobile, Tablet, Desktop)
- Beautiful and clean UI matching the design reference
- Working Add-to-Cart functionality
- Cart Drawer with quantity control and remove option
- Live cart count badge
- Cart data saved in localStorage
- Smooth scrolling navigation
- Toast notifications for user actions
- Order success popup after checkout
- Modern component-based structure

---

## Tech Stack

- React (with Hooks)
- Vite
- CSS (Custom Properties)
- React Context API + useReducer
- LocalStorage
